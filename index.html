🆓 무료로 시작하기 (Gemini · Groq · OpenRouter)

무료 키 하나만 넣으면 피클·Gemini·Groq 셋 다 진짜 AI로 답해요. 셋 다 카드 등록 없이 무료이고, Gemini → Groq → OpenRouter 순서로 시도하다가 한도 초과·장애면 저장된 다음 무료 키로 자동 전환해요.

⚡ Groq

console.groq.com/keys → Create API Key 를 누르면 카드 등록 없이 무료로 발급돼요.

기본 모델은 무료·빠른 openai/gpt-oss-120b 예요. Llama 계열은 2026년 8월 이후 무료 티어에서 빠져서 기본값으로 쓰지 않아요. 모델이 내려가면 openai/gpt-oss-20b → qwen/qwen3.8-27b 순서로 자동으로 바꿔 답해요.

🤖 Gemini

aistudio.google.com → Get API key 를 누르면 카드 등록 없이 무료로 발급돼요.

기본 모델은 무료·빠른 gemini-3.5-flash-lite, 더 똑똑한 답을 원하면 gemini-3.8-flash(역시 무료)를 넣으세요. gemini-2.5-flash는 새 키에서는 더 이상 열리지 않고, 무료 한도를 넘기면 잠시 뒤 다시 시도해 주세요.

🌐 OpenRouter

openrouter.ai/keys → Create Key 로 무료 키를 받아요. 기본 모델 openrouter/free 는 카드 없이 쓸 수 있고, 한도를 넘기면 Gemini·Groq로 다시 넘어가요.

연결 상태
Groq확인 중
Gemini확인 중
피클확인 중

무료 키가 있으면 Gemini → Groq → OpenRouter 순서로 답하고, 한도 초과·장애·키 없음이면 다음 무료 키로 자동 전환해요. 무료 키가 하나도 없을 때만 데모로 답합니다.

💳 유료 엔진 키 직접 고를 때만

여기 키를 넣어도 자동 답변에는 쓰지 않아요. 그 AI의 엔진을 직접 골랐을 때만 호출합니다. 무료 엔진만 쓰려면 비워 두세요.

키는 이 브라우저의 localStorage에만 저장되고 그 외 어디에도 전송되지 않아요. 각 AI 호출에만 쓰입니다.

여기 값도 아래 「모든 설정 한 번에 저장」으로 함께 저장돼요.

☁️ Cloudflare Worker 선택

Worker 주소를 넣으면 브라우저에 API 키가 없어도 Worker가 대신 불러요. 비우면 지금처럼 브라우저 키로 직접 부릅니다.

🔒 화면 잠금

지금은 잠금이 꺼져 있어요. 비밀번호를 정하면 페이지를 열 때마다 잠금 화면이 먼저 보여요.

비밀번호는 SHA-256 해시로만 이 브라우저(localStorage)에 저장돼요. 잊으면 브라우저 저장값을 지우면 되고, 대화 내용은 그대로 남아요.
